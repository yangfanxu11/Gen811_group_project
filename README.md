## Background

BDP1 is a bromodomain-containing protein in *Toxoplasma gondii*. Bromodomains recognize acetylated lysines on histones and are typically involved in chromatin regulation. Co-IP mass spectrometry experiments identified BDP1 as an interactor of both CHD1 (a chromatin remodeling factor) and PRP8 (a core spliceosome component) (Fleck et al., 2023). This dual interaction raised the possibility that BDP1 might coordinate chromatin state with RNA splicing.

Alternative splicing allows a single gene to produce multiple mRNA isoforms by selecting different combinations of exons. In other eukaryotes, chromatin structure can influence splicing by affecting RNA polymerase II elongation rate—fast elongation favors exon skipping while slow elongation allows weak splice sites to be recognized. If BDP1 links chromatin remodeling to the spliceosome, its depletion might alter splicing patterns genome-wide.

We analyzed RNA-seq data from BDP1 knockdown parasites to determine whether BDP1 regulates alternative splicing in *Toxoplasma*.

## Dataset

**Experimental design:**
- Wild-type: 4 biological replicates (WT1-4)
- BDP1 knockdown: 2 biological replicates (KD1-2)
- Knockdown method: AID-inducible degron system
- Organism: *Toxoplasma gondii* ME49 strain
- Reference genome: ToxoDB release 68

**Note:** KD3 and KD4 were excluded due to library construction failure during the RNA-seq preparation.

**Data location:** RNA-seq BAM files generated by STAR aligner are in `data/RNASEQ/alignment/star/`. Each sample has a corresponding `SJ.out.tab` file containing splice junction coordinates and read counts.

## Analysis Approach

We used **Leafcutter** (Li et al., 2018), an annotation-free method for detecting differential splicing. Instead of quantifying known isoforms, Leafcutter works directly with junction reads from the aligner.

**How Leafcutter works:**
1. Groups junctions that share a splice donor or acceptor site into "intron clusters"
2. Within each cluster, tests whether the relative usage of junctions changes between conditions
3. This captures exon skipping, alternative 5'/3' splice sites, and intron retention

For example, if a gene has two junctions—one including an exon and one skipping it—Leafcutter tests whether the inclusion/skipping ratio changes after BDP1 knockdown.

**Why this approach?**  
*Toxoplasma* has extensive alternative splicing and PacBio Iso-Seq data from our lab shows extreme isoform complexity (up to 140 isoforms per gene). Annotation-based methods would miss unannotated splice variants. Leafcutter's annotation-free approach detects any junction with sufficient read coverage.

## Methods

### 1. Junction Extraction (`01_leafcutter_prep.sh`)

STAR outputs splice junctions in `SJ.out.tab` format. We converted these to BED6 format required by Leafcutter:
- Extracted chromosome, start, end, strand, and read counts
- Filtered for junctions with strand information (strand=1 or 2 in STAR)
- Generated one `.junc` file per sample

### 2. Leafcutter Clustering (`02_run_leafcutter.sh`)

The Leafcutter clustering script:
- Identified junctions sharing splice sites across all samples
- Grouped them into 3,008 intron clusters
- Applied coverage filters (minimum reads per junction, minimum samples)
- Output: `leafcutter_perind.counts.gz` containing junction read counts per sample

### 3. Differential Testing (`03_edgeR_analysis.R`)

We used edgeR instead of Leafcutter's built-in Dirichlet-Multinomial model because:
- Better compatibility with unbalanced designs (4 WT vs 2 KD)
- More robust handling of low-count junctions
- Standard GLM framework for RNA-seq differential testing

**Statistical model:**
- Extracted junction counts from Leafcutter output
- Filtered junctions with ≥10 reads in ≥2 samples
- Tested 3,635 junctions using edgeR's quasi-likelihood GLM
- Applied FDR correction (Benjamini-Hochberg)
- **Result: 1,791 significant junctions at FDR < 0.05**

### 4. PSI Calculation (`04_calculate_psi.R`)

For each junction, we calculated Percent Spliced In (PSI):
PSI = junction_reads / cluster_total_reads × 100
ΔPSI = PSI_KD - PSI_WT

This quantifies the magnitude of splicing changes.

### 5. AS vs TSS/TES Classification (`23_correct_AS_classification.R`)

**Problem:** Not all differential junctions represent alternative splicing. Some might be alternative transcription start sites (TSS) or termination sites (TES) producing different pre-mRNA molecules.

**How we distinguished them:**

- **Multi-junction clusters** → Alternative splicing
  - If ≥2 junctions in a cluster are significant, they must share splice sites
  - Shared sites means they're splicing the same pre-mRNA differently
  - Example: junction A (exon1-exon2) and junction B (exon1-exon3) share the exon1 donor → exon skipping

- **Single-junction clusters** → Likely TSS/TES
  - Only one junction in the cluster shows differential usage
  - Doesn't share sites with other changing junctions
  - More consistent with different transcription boundaries

**Further refinement:**
- **Competitive AS** (44 clusters): same cluster has junctions going opposite directions (some up, some down)
  - Strongest evidence for exon inclusion/skipping switches
  - Example: inclusion junction decreases while skipping junction increases
- **Consistent AS** (296 clusters): all junctions in cluster change the same direction
  - Could be coordinated splicing regulation or transcription effects

### 6. Visualization (`24_final_figures.R`)

Generated summary figures showing:
- AS vs TSS/TES classification breakdown
- Cluster complexity distribution
- Effect size comparisons
- Direction of changes (up vs down)

## Results

### Overall Statistics

**1,791 significant differential junctions** (FDR < 0.05) from 1,338 affected clusters

**Classification:**
- **Alternative Splicing: 793 junctions (44.3%)**
  - 44 competitive AS events (strongest evidence for splicing regulation)
  - 296 other AS events (consistent direction)
  - From 340 multi-junction clusters
  
- **Alternative TSS/TES: 998 junctions (55.7%)**
  - From 998 single-junction clusters
  - Likely transcription boundary changes

**Direction:**
- 773 junctions: increased usage in KD (BDP1 normally represses)
- 1,018 junctions: decreased usage in KD (BDP1 normally promotes)

**Effect sizes:**
- Median |logFC| for AS junctions: 1.33
- Median |logFC| for TSS/TES junctions: 1.57
- Median |ΔPSI|: relatively small across both categories

### Interpretation

The data show that BDP1 knockdown affects both alternative splicing and transcription boundaries. However, the effect sizes are modest, and the small sample size for knockdown (n=2) limits statistical power. While we observe statistically significant changes in junction usage, the biological significance of these changes remains unclear without functional validation.

The 44 competitive AS events—where junctions within the same cluster change in opposite directions—provide the most convincing evidence for altered splice site choice. However, most differential junctions come from single-junction clusters, making it difficult to distinguish true splicing changes from transcription start/end site variation.

Further experiments with more KD replicates, additional validation methods (qPCR, isoform-specific functional assays), and integration with other data types (ChIP-seq for BDP1 binding, nascent RNA-seq for transcription dynamics) would be needed to determine whether BDP1 plays a direct functional role in splicing regulation.
